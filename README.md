# VCA Muzon Website

This is the Production repository for the Victory Churches of Asia - Muzon
website.

## Repositories

- Production: https://github.com/yzcreativetech/vca-muzon-website
- UAT/testing: https://github.com/yzcreativetech/vca-muzon-website-uat

The Production branch is `main`, and the website is hosted with GitHub Pages.
A custom domain is planned but is not yet configured.

## Deployment workflow

Changes are developed and tested in the UAT repository first. After review and
approval, approved changes are promoted to this Production repository and
deployed from `main` through GitHub Pages.

## Local worktrees

- Production: `C:\WebProjects\VCA Web Project\vca_website_prod`
- UAT: `C:\WebProjects\VCA Web Project\vca_website_uat`
